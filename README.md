# 5-Build
Module 5 Build
Indie Film Collective Website

Project Description

This project is a multi-page website for an independent film collective. The website provides information about upcoming film screenings, workshops, and collaboration opportunities. It was created to demonstrate the use of HTML, CSS, responsive design, and accessible web development practices.

Website Pages

The website includes four main pages:

Home (index.html): Introduces the independent film collective and provides an overview of its purpose.

Screenings (screenings.html): Shares information about film screenings and upcoming events.

Workshops (workshops.html): Provides information about workshops and learning opportunities.

Collaborations (collaborations.html): Highlights opportunities for creative collaboration.

Technologies Used

HTML5

CSS3

Responsive design using CSS media queries

CSS Grid and Flexbox

Responsive Design

The website uses a mobile-first approach. The layout adjusts to different screen sizes using CSS media queries. On smaller screens, content is arranged vertically. On larger screens, the layout changes to display navigation and content in a wider arrangement.

Accessibility

Accessibility was considered throughout the project by using semantic HTML elements, descriptive image alt text, and readable text colors.
